# Automated Nmap Scanner

## Overview
A Python-based automated Nmap scanner for performing network reconnaissance and service enumeration.

## Features
- Basic Scanning
- Service Version Detection
- OS Detection
- Aggressive Scanning
- Automatic Report Saving

## Technologies Used
- Python
- Nmap

## How to Run

```bash
python3 scanner.py
```
